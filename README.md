# Цех — библиотека управляющих программ

Сайт для Толика: проекты, схемы, явный порядок операций, неизменённые NC, история версий и локальные отчёты. Исходные NC остаются в корне. Приложение — docs/, без сборщика, сервера приложения и секретов.

## Работа
- Адрес после включения GitHub Pages: https://111l9lpa.github.io/File-obmrn/
- Публикация пока требует включения Pages владельцем: API интеграции вернул403. В Settings → Pages выбрать Deploy from a branch → main → /docs → Save.
- Готовая автономная версия: CNC_LIBRARY_OFFLINE.html в корне репозитория. Скачать и открыть браузером; включает17NC и все схемы.
- Сохранить проект офлайн: текущие NC и изображения в IndexedDB; оболочка в Service Worker.
- Скачать библиотеку для ПК: один HTML со всеми программами, изображениями и интерфейсом. Подходит для переноса по шнуру, не требует Python/Node. Открыть современным Яндекс/Chrome. На конкретном Windows7 требуется проверка пользователем: эта ОС и версия его браузера недоступны в среде разработки.
- Импорт NC/картинок/JSON, подписание локальных файлов и привязка к проекту. Сохранение исходных байтов.
- Отчёт оператора и фото привязаны к SHA-256. Это локальные записи, не удалённая синхронизация между устройствами.
- Экспорт JSON содержит сохранённые файлы и записи; импорт проверяет хеши до восстановления.
- Обновление каталога с подтверждением, прежние версии остаются в истории. Неописанные NC из GitHub — «Неразобранные».

## Ограничения
Приложение не рассчитывает траектории и не оценивает безопасность обработки. Исходные PNG/SVG показываются как схемы. Реального управления станком нет. Нет фоновой записи в GitHub, автоматической синхронизации отчётов, аккаунтов или Firebase. Очистка данных браузера может удалить локальное содержимое; делайте HTML/JSON-копии. Поиск новых файлов GitHub ограничен100 за одно обновление и лимитами публичного API. Приложение не обходит лимиты — показывает ошибку и сохраняет локальные данные.

## Продолжение разработки
python -m http.server 8765 — сервер корня репозитория, открыть http://localhost:8765/docs/.
node --test tests/core.test.js
python tools/package_site.py
node tests/browser.cjs — нужен Playwright и Chromium; текущий сценарий использует /usr/bin/chromium. В управляемом браузере file:// запрещён политикой, поэтому автономный HTML дополнительно проверяется через локальную раздачу с блокировкой всех зависимостей и отключением сети. Не выдавать это за тест на Windows7.

Каталог: docs/catalog.json, схема docs/catalog.schema.json, инструкция tools/CATALOG_GUIDE.md. GitHub Pages: main → /docs. После изменений JS/CSS/каталога пересоздать sw.js и portable-template.json. Предыдущие NC не менять и не удалять.
