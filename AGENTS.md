# Библиотека ЧПУ Толика
- Не менять байты существующих NC. Новая геометрия/режимы = новый файл и новая версия.
- Сайт находится в docs/, публикация GitHub Pages из main:/docs. Секретов в клиентском коде быть не должно.
- При добавлении NC ОБЯЗАТЕЛЬНО обновлять docs/catalog.json по tools/CATALOG_GUIDE.md. Не угадывать неизвестные сведения.
- Проверка хеша, проверка геометрии и сообщение о реальном резе — разные статусы. Подтверждение одной детали не подтверждает весь файл.
- Порядок операций задаётся order, а не номером файла. Для панели40→42→41.
- URL NC закреплять за коммитом с опубликованными исходными байтами. Изменённые байты нельзя выпускать под прежним хешем.
- Схемы должны соответствовать указанной версии/геометрии. Сохранять старые программы и контекст.
- После изменения интерфейса/каталога: node --test tests/core.test.js; python tools/package_site.py. Обновляются portable-template.json и sw.js. Затем python tools/build_portable_snapshot.py обновляет автономный CNC_LIBRARY_OFFLINE.html без локальных отчётов. Browser QA: tests/browser.cjs (нужен сервер на8765 и Playwright). В управляемом Chrome file:// заблокирован; не обходить политику.
- Не запускать станок, не отправлять команды. Интерфейс только хранит, отображает и скачивает.
- Локальные записи оператора не публиковать без разрешения пользователя. Тестовые снимки/файлы не коммитить.

- «70×20» в декоративном паттерне — условное имя. По cut_bubishki.NC и подтверждённой исходной D6 размер готовой узкой детали67,001×13,8001мм. Не подменять условное название готовым размером. Файл47 ошибочный; исправление48 учитывает первую уже вырезанную деталь.
